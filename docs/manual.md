# ClubDesk 操作手册

知华科技（上海如静知华信息科技有限公司）· https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

## 场馆第一次配置

1. 管理员在“账号与设置”核对门店名称、IANA时区和启停，参数中设经营主体与币种。建立套餐/卡后币种锁定，建立卡/课次后门店时区锁定，不能事后改写合同和课程日期意义。
2. 在“课程与套餐”建教室和容量、教练、课程项目及默认时长/名额、次卡或期限卡套餐；启用所需分类。教练及教室不能重叠排课。课程类别维护在后台分类页。
3. 新增或CSV导入会员。代码固定且大小写归一，档案门店不能转换；已有引用不可删除，仍有未完成预约时不能直接停用会员。
4. 给前台建立有对应门店权限的账号。给会员建立MEMBER范围、仅会员入口权限的账号并绑定会员；给教练建立TRAINER范围、仅指派课程权限的账号并绑定教练。两种身份不能混绑，也不能把旧会员账号变成员工。

每个员工属于一个门店，系统管理员可跨门店。默认前台收银可代约、现场签到及资金登记；运营可排课、维护资料、开卡与处理预约；财务可查看本门店及登记资金，教练只看本人已指派课程。自定义角色权限可减少，菜单名称/顺序/启停可维护；路由与接口权限映射由系统登记，不能通过修改菜单赋予接口权限。

## 开卡、收款与续开

选择会员、启用套餐、门店本地开始日期。卡保存套餐名称、价格、课时、币种及有效日期快照；开始日期到结束日期均包含当日，有效天数30表示开始日至第30个本地日期末。

待收款卡不能预约。财务或前台登记**已核实的实际外部收款**，填写真实凭据和依据，可分次、不超收；达到约定价格后生效。系统不会向支付渠道发起扣款。会员卡详情可核对约定金额、待收、净收款、原收款可退金额和原始记录。

期限卡可在有效期内预约不限课次，也可登记每日一次场馆到店；次卡每个课次核销一次，仅作为课程权益。没有储值余额或共享卡。续开是另一张卡，手工选择接续日期，不改变原卡，不自动扣费或发送提醒。

## 排课与预约

输入**门店当地时间**，选课程、同门店教练、教室、名额和提前取消时限。时长来自课程项目并固化在课次，名额不能超过教室容量。夏令时缺口或重复时间会明确拒绝，换一个唯一的时间。草稿核对后发布。

会员登录，在可约课程选择课次和自己的可用卡；前台可以代约。系统检查：已发布且未开课、卡已生效、整节课在卡有效期内、不在冻结区间、有未预留课时、名额未满、本人没有重叠课。一个会员同课次只能有一条当前预约，取消后再约保留全部变更历史。

卡的“可预约课时 = 总次数 − 预留 − 已核销”。预约先预留，签到才核销。期限卡不显示虚假的次数余额，但预留及核销历史仍记录。

修改已发布课程先撤回，存在有效预约时不能撤回或改时间。取消课程须说明原因并释放全部未核销预约；有已核销记录时须先核对纠错，不能直接抹除到课事实。只有课程真实结束后才可结课，剩余未签到人员按核对后的未到规则核销。

## 现场扫码与人工核验

会员手机在签到码页生成动态二维码，两分钟有效、单次使用。刷新使旧码失效，五秒内不能反复刷新。码不包含手机号或客户链接，数据库只保存散列。

前台到店签到页选择课次，扫描会员码：

- 键盘式扫码枪向输入框送入完整文本及回车；不需要本项目专用设备SDK。
- 摄像头按钮用本机浏览器授权的摄像头读取；要求HTTPS或本机安全来源。未授权、不安全来源或无设备时给出明确提示，可换扫码枪、图片读取或人工名单核验。
- 二维码图片仅在本地浏览器识别，不上传服务器。
- 列表人工签到仍需授权员工或被指派教练，并登记核验说明。

签到开放在开课前30分钟至课后30分钟；核验真实到课人员后才能登记。二维码过期、用过、选错课次、没有预约或卡无效会被拒绝，失败不会扣课时。场馆到店模式仅用当前有效期限卡；存在多张时优先使用最早到期的有效卡，每本地日期只登记一次，不能当作门禁开锁。

## 取消、未到与纠错

会员在课次的提前取消期限前自行取消并返还预留，截止时刻及以后不能自行取消。前台处理实际例外须记录原因，不隐藏操作。

课次结束后，教练或前台核对未到预约并核销一次。结课确认会将剩余BOOKED预约记为NO_SHOW。核销录错由有会员操作权限的岗位新增纠错流水、返还已用课时并将预约取消；原签到或未到流水继续保留。

## 冻结、关卡、退款及冲正

冻结只能对当前有效卡，1–90天，累计实际延期不超过365天，期间已有预约须先处理；有效期随冻结天数延长。提前解冻扣回未使用延期，若会使未来预约超出到期日则拒绝，须先处理预约。时间经过冻结结束日后状态自动派生为有效，不重写资金和业务历史。

关卡保留协议和历史，取消其所有未完成预约并释放预留，不返还已实际核销课时。退款需要实际外部退款凭据，关联原收款，不能超过该原收款扣除未冲正退款后的可退金额。退款金额由工作人员按线下约定核对，不按课时自动计算。

错误资金记录通过一次完整金额冲正追加反向记录，不修改原金额。生效卡先关卡，原收款有未冲正退款时先解决退款依赖。冲正必须对应真实外部凭据，本系统不执行或证明资金移动。

## 导入、导出与异常

新增会员CSV表头：`code,name,departmentId,contactNote,enabled`。enabled填写true或false，门店编号在导入窗口列出。最多300条，UTF-8；支持引号、转义引号和换行。先预览再确认，同批重复代码、无权限门店或任一错误行将整批回滚，反馈安全记录号和原因。模板为空表头，不上传客户资料到源码仓库。

经营报表按每个门店本地日期，显示收款和退款各自包含冲正后的值，净收款=收款−退款；全公司总计来自同一组门店之和。到课和未到按课次日期，到店按本地到店日期。可导出会员、卡、出勤与资金CSV，文本公式前缀被转义，数据库原始文字不改变。不是总账或税务账表。

保存失败时原输入保留；若保存成功而重载失败，提示已保存，不能再登记一次。未收到写入响应显示结果不明，停止再次确认，关闭后刷新核对。版本过期先重新读取，不自动覆盖其他员工变更。会话失效会清空页面表单与私有缓存；权限或门店变化时清理旧范围资料。
