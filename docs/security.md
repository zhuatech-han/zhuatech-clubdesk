# ClubDesk 安全与反馈

知华科技（上海如静知华信息科技有限公司） · [官网](https://www.zhuatech.cn/) · 商业授权或深度定制开发微信 zhuatech、zhuatech2。

- 三份独立随机初始口令仅在本机0600 `.env`，初始化脚本拒绝覆盖。没有公共管理员演示密码；`.env.example`只列变量。
- 密码BCrypt12轮，12–72字节、含大小写与数字。会话HttpOnly/SameSite=Strict；登录、写入、退出使用CSRF。部署HTTPS设置COOKIE_SECURE=true。账号停用、密码或当前资料范围变化会使旧权限失效；客户端清理不再授权的旧记录。
- 接口每次核验权限和门店、会员、教练范围。会员仅本人，教练仅指派课程且无联系资料/金额；最后管理员和内建菜单路由权限不可破坏。前端隐藏按钮不能替代服务端权限。
- 金额、状态、引用、版本、容量与冻结期限均服务端核验。导入最多300条，错误整批回滚；CSV导出对空白或控制字符后的公式前缀作转义。输入通过文本渲染，不执行CSV内容。
- 短码2分钟、单次、5秒刷新间隔；只存散列。前台核验实际在场身份，不能凭截图承诺防代签。二维码图片只在浏览器解码，不作为服务器文件上传。
- 数据库不暴露主机端口，默认前端绑定127.0.0.1；只有健康Actuator开放。Nginx关闭访问日志，有CSP、nosniff、DENY及同源限制。应用不用日志输出口令或短码。
- 不读取客户生产数据作为演示；测试仅TEST资料。真实备份、测试登录口令、会话和扫码图不能提交。目录与导出中不插入广告或公开客户记录。

这是单实例学习版：会话和登录失败限流在单实例内工作，没有SSO、MFA、跨节点限流、独立租户数据库或外部身份供应商。公网部署须另核对可信代理、TLS、限速、备份访问、审计保留与实际隐私规则；外部数据库要求可信CA和证书校验。

Issues只用于脱敏的业务复现及版本反馈。漏洞和敏感细节通过[官网](https://www.zhuatech.cn/)或上述微信私下沟通，不把密钥、客户文件或数据库发到公开仓库。
